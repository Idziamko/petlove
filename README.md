# Petlove

A pet adoption website with pet listings, animal news, partner organisations and a personal profile.

The project is being updated to match the design and all assignment requirements.

## Links

- Repository: https://github.com/Idziamko/petlove
- Website: https://idziamko.github.io/petlove/
- Design: https://www.figma.com/design/puMNfZVg4YI8UZoJ1QiLLi/Petlove
- API documentation: https://petlove.b.goit.study/api-docs/

## Technologies

React, TypeScript, Vite, React Router, Axios, Formik and Yup. The interface uses CSS and Manrope.

## Local setup

Use Node.js 22 or later.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Pages

Home, News, Find pet, Our friends, Login, Registration, Profile and Add pet.

The application uses the Petlove API for authentication, news, pet listings, partner details and user data. Forms use Formik and Yup. The layout supports mobile, tablet and desktop screens.

## Deployment

Changes pushed to main are built and deployed to GitHub Pages. The workflow sets the project base path and includes a fallback page for direct route links.
